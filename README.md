# HHU 白鲨垒球队训练计划库

为球队建立一套可复用、可分层、可持续更新的训练资料。默认每周训练 **周一、周三、周四**，每次约 **90 分钟**；教练可按场地、人数、天气和赛事安排调整。

> 适用对象：初学者至进阶练习者。本文是球队训练组织参考，不替代教练现场指导；出现疼痛、眩晕或不适时立即停止并告知教练。

## 每周结构

| 日期 | 重点 | 推荐内容 |
| --- | --- | --- |
| 周一 | 投打基本功 | 动态热身、投接球渐进、挥棒技术、短距离击球 |
| 周三 | 守备与传接 | 接球手型、滚地球/高飞球、脚步与传球、位置轮换 |
| 周四 | 跑垒与综合应用 | 跑垒判断、情境练习、分组对抗、简短体能与复盘 |

建议同一周期内保持训练主题稳定，逐步增加质量或难度，不要同时大幅增加训练量和强度。初学者先练动作控制与安全；进阶队员增加方向、速度、判断和情境压力。

## 使用约定

1. 每堂训练指定一位负责人，先说明目标、场地边界、器材摆放和停止口令。
2. 每项练习标注人数、器材、时间、要点及降阶/进阶方式；人数多时设置轮转站，避免排队过久。
3. 新动作先低速、短距离、低强度练习；动作稳定后再逐步增加速度或复杂度。
4. 记录出勤、训练主题、主观疲劳（1–5）和需要跟进的问题；不以疼痛作为“练到位”的标准。
5. 视频仅用于辅助理解。优先参考合格教练示范；训练现场以教练针对队员的反馈为准。

## 训练记录建议

每次训练记录：日期、参加人数、天气/场地、目标、实际练习及用时、队员主观疲劳（1–5）、完成情况、伤病/不适（仅记录必要信息）、下次调整。可复制 [单次训练模板](plans/session-template.md)。
