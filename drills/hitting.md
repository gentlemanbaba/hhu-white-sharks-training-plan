# 打击练习

**安全底线：** 一次只允许一名击球者进入击球区；旁人留在指定等待区。使用适合的头盔和防护。未收到负责人许可，不挥棒、不捡球；击球区周围保持明确边界。

## 1. 无球平衡挥棒

- **器材：** 合适重量的球棒；有需要时先徒手练习。
- **做法：** 先练站姿、握棒和准备，再以可控速度完成短组挥棒；每次挥棒后站稳。
- **提示：** 视线稳定、保持平衡、动作顺畅；不追求最大力量或挥棒数量。
- **降阶：** 徒手分解动作或使用更轻的训练棒。
- **进阶：** 对明确方向做可控挥棒，保持动作质量。

## 2. 静止球/架球击打

- **做法：** 在教练安排的安全击球区使用适合球具；每人轮流短组击打，其他队员留在等待区。
- **提示：** 击球前确认教练和场地准备好；完成挥棒后听指令再离开击球区。
- **降阶：** 软式球、较大的目标、低强度挥棒。
- **进阶：** 选择击球方向或目标区，不以击球距离作为唯一标准。

## 3. 轻柔手抛球

队员动作稳定且场地管理到位后，由教练在安全位置轻柔手抛容易击打的球。先练准备与判断，再尝试击打。投球者和击球者确认准备好才开始；球路失控时立即停止该轮。

## 4. 练习组织

采用短轮次，减少等待和疲劳累积；每轮反馈一项重点即可。球棒挥动范围内禁止其他人进入。捡球前收起球棒并由负责人确认停止击球。
