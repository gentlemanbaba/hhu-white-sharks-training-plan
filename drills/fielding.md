# 守备练习

**重点：** 准备姿势、观察来球、控制身体、完成接球后再传球。初学者使用慢速、容易判断的来球。

## 1. 准备姿势与正面滚地球

- **组织：** 两人一组或教练滚球；前方有足够空地，旁观者在安全区域。
- **做法：** 先无球练准备姿势；再从近距离接正面慢速滚地球，接稳后停住并回传。
- **提示：** 眼睛跟球、身体保持平衡、双手配合；接球后确认目标再传。
- **降阶：** 原地接停球或更慢的球，缩短距离。
- **进阶：** 在稳定后加入左右小范围移动或明确的传球目标。

## 2. 左右移动接球

- **做法：** 教练或伙伴将球轻轻滚向左右可控范围；队员先移动到球路，再接球、稳定、回传。
- **提示：** 先判断再移动，不扑向超出能力的球；一次只增加一个变化。
- **降阶：** 球路靠近身体中线，速度慢。
- **进阶：** 扩大可控范围或加入教练口令，但不同时提升速度和距离。

## 3. 高飞球判断与沟通

- **安全前提：** 使用合适球具和开阔场地；先教喊话、避让和接球区域，不安排人员互相冲撞。
- **做法：** 从容易、短距离的高抛开始；队员先判断落点并喊出队内约定的呼叫词，再尝试接球。
- **降阶：** 先追踪不接，或使用软式球、较低抛球。
- **进阶：** 加入轻微左右偏移和队友沟通，始终避免争抢碰撞。

## 4. 守备—传球组合

队员处理一个容易的滚地球，接稳后向大目标传球。先分开练接球和传球，再组合。目标是动作连贯、沟通清楚，而不是强行追求速度。出现失控或疲劳时退回简单版本。
