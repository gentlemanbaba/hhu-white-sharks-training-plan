# 跑垒与基础体能

**重点：** 认识安全路线、控制加速与减速、观察教练信号和与队友沟通。先无对抗练习；不熟练的队员不做碰撞或滑垒练习。

## 1. 起跑、加速与减速

- **做法：** 在平整、无障碍的直线路径上做短距离轻松加速，逐步减速并回到队伍；保持间隔。
- **提示：** 根据场地和队员状态选择距离；重视控制，不要求每轮全力冲刺。
- **降阶：** 快走到轻松慢跑。
- **进阶：** 队员状态良好且动作稳定时，加入明确的视觉/口令信号。

## 2. 触垒路线

- **做法：** 先步行沿安全路线经过垒包，练习看标记、触垒和听教练信号；熟悉后再轻松跑动。
- **提示：** 跑道保持清晰，前一名队员离开冲突区域后下一名再出发。
- **降阶：** 单垒往返、无计时。
- **进阶：** 增加观察信号和选择跑/停的情境，不增加碰撞风险。

## 3. 观察信号与决策

教练在安全距离发出预先说明的“继续/停止/回垒”信号，队员按规则完成路线。先慢速确保理解，再逐步加入判断。错误时停下来解释，不以惩罚冲刺代替教学。

## 4. 基础体能游戏

可选短时、低风险的接力、平衡或灵敏度小游戏。设置足够间距、清晰路线和休息；根据年龄、经验、场地及天气调整。若动作变形、疲劳过高或出现不适，立即降阶或停止。

## 结束整理

以轻松步行和队员自选的舒适活动结束，询问训练感受并补充饮水。任何疼痛或令人担忧的不适都应停止相关活动并告知负责人。
