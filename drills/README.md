# 练习目录

每项练习开始前说明目标、边界、轮转方式和停止口令。先保证动作可控，再按队员能力调整难度。具体分组和用时可参照 [单次训练模板](../plans/session-template.md)。

## 技术主题

- [投球与接球](throwing-catching.md)：准备姿势、轻松传接、接球后的动作顺序。
- [守备](fielding.md)：准备姿势、地滚球、高飞球判断、传球与沟通。
- [打击](hitting.md)：无球挥棒、静止球、手抛球和方向性练习。
- [跑垒与体能](baserunning-conditioning.md)：路线、触垒、加减速与基础体能游戏。

## 设计一项新练习

请写清楚：技能目标、适用水平、人数、器材、场地布局、动作提示、每轮时间、初学者降阶、熟练者进阶、停止规则。避免只写“多练”“跑到累”为训练目标。

## 视频参考方式

外部视频随时可能变更，建议用下列关键词在可信教练或垒球/棒球教学渠道检索，并由教练确认动作适合队员和器材：

- 投接球：`棒球 基础传接球 教学`、`softball throwing catching fundamentals`
- 守备：`棒球 正面地滚球 基础教学`、`softball fielding ground ball fundamentals`
- 打击：`棒球 静止球挥棒 基础教学`、`softball tee hitting fundamentals`
- 跑垒：`棒球 跑垒触垒 基础教学`、`baseball baserunning fundamentals`

视频是辅助参考，不代替现场安全管理或个别指导；若示范与队内教学、安全规则不一致，以教练现场指导为准。
